## Preview and SiteGround upload

Open any of the three HTML files to preview it. Use the language menu in the header to move between versions. Keep the two language directories alongside the English homepage.

To publish, extract the SiteGround ZIP into the intended domain’s `public_html` directory. The root should contain `index.html`, `el/`, `ru/`, `sitemap.xml` and `robots.txt`. The public server must serve each directory’s `index.html` as its index.

Each page declares its own canonical address, links to all three languages using `hreflang`, and uses the English homepage as `x-default`. After launch the sitemap is available at `https://urbanedgegroup.com.cy/sitemap.xml`.
