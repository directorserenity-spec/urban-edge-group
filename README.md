# Urban Edge Group

A one-page directory of the five Urban Edge Group ventures and an introduction to Chris and Dimos in Limassol, Cyprus.

## Preview

Open `index.html` in a browser. The page includes its styles and artwork and runs without a build step.

## SiteGround

When the group domain is ready, upload `index.html` to that domain’s `public_html` directory. If using the prepared SiteGround ZIP, extract it there so the file sits directly inside `public_html`.

## Venture links

The directory links to Eco Shield, ASI-NEXUS, DJ Chris NRG on Facebook, and Urban Edge Barbers. UE Studios is marked as in development until its website address is ready.
